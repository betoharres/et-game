These PNG icons were rendered from selected low-poly meshes found in the
user-provided asset library:

`C:\dev\godot_3d\assets\_SourceFiles\OBJ`

`tools/render_prototype_icons.py`. The PNG files are derived assets used by the
Godot UI; the original OBJ/FBX files are not copied into this repository.
