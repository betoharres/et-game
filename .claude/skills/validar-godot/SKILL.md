# Validar uma alteração no ET Game

O procedimento está em `tools/VALIDACAO.md`. **Leia esse
arquivo antes de validar** — ele traz os comandos, o mapa de ferramentas de
`tools/` por sistema, os roteiros de teste manual e as regras para escrever uma
verificação nova.

Ele fica fora de `.claude/` de propósito: o projeto é desenvolvido com Claude
Code e Codex, e o procedimento precisa valer para os dois. Esta skill só existe
para carregá-lo na hora certa; mantenha o conteúdo lá, nunca aqui.
